# Таблетница

Мобильная PWA на GitHub Pages. Вход и регистрация — через Puter, как в соседнем планере «Свод». Пароли Supabase в приложении больше не запрашиваются.

## Память

Курсы, отметки и снимки расписания по дням сохраняются локально отдельно для каждого UUID Puter и синхронизируются с приватными KV-записями `tabletbox.v2.<uuid>.*`. Namespace отличается от `svod.v1.*`; расходы и задачи планера не изменяются. Изменения курсов действуют с текущего дня, прошлые расписания и факты приёмов сохраняются. При ошибке облака остаётся локальная копия и признак ожидающей синхронизации.

## Перенос старого дневника

После входа: Настройки → Аккаунт → Перенести старые курсы и календарь. Выберите свою локальную копию, JSON-экспорт или загрузку своего ранее авторизованного Supabase-аккаунта. Просмотрите сводку и подтвердите принадлежность данных перед записью в текущий Puter-аккаунт. Повторный импорт использует ID записей и не дублирует отметки. Источники не удаляются.

Автоматического доступа ко всем серверным пользователям Supabase нет. Если старый сеанс истёк, а локальной или JSON-копии нет, необходим экспорт владельцем Supabase. Пароли и администраторские ключи не помещаются в исходники, импорт или Git.

## Проверка и публикация

`npm test` — очередь приёмов, история, редактирование/архив курсов, границы темы по Дубаю, изоляция двух пользователей, повторный вход, второе устройство, конкурентные добавления, длинная история, ошибки записи и миграция. Автотесты Puter используют изолированный тестовый провайдер; реальное создание учётной записи пользователь проходит в окне Puter.

Опубликуйте содержимое папки на HTTPS-хостинге. Рабочий адрес: https://svlat.github.io/tabletbox/. Соседние папки SLOT и svod не принадлежат этой сборке и не должны перезаписываться. При следующем обновлении меняйте CACHE в sw.js и версии изменённых модулей.

## Напоминания и тема

Тема переключается по Asia/Dubai: 09:00–17:00 светлая, остальное время тёмная. Серверная отправка push-напоминаний при полностью закрытом приложении пока не подключена.
