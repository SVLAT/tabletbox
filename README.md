# Таблетница

Это статическая PWA-версия приложения для напоминаний о лекарствах.

## Публикация

Загрузите всё содержимое папки на статический HTTPS-хостинг: Netlify, Vercel, Cloudflare Pages, GitHub Pages или собственный домен. Затем на телефоне откройте опубликованный адрес и выберите «Добавить на экран Домой».

## Аккаунт и статистика

Текущая версия сохраняет данные и локальный профиль в браузере устройства. Для настоящего входа по email и синхронизации статистики:

1. Создайте бесплатный проект в Supabase.
2. В SQL Editor выполните [supabase-schema.sql](./supabase-schema.sql).
3. В Authentication → URL Configuration добавьте адрес опубликованного сайта в Site URL и Redirect URLs.
4. Скопируйте Project URL и публичный anon key в [supabase-config.js](./supabase-config.js).

После этого в «Настройки → Аккаунт» пользователь вводит email, получает Magic Link и получает свои сохранённые данные на любом устройстве.

## Уведомления

Для установки PWA и фоновых уведомлений требуется HTTPS. Для гарантированных напоминаний при полностью закрытом приложении нужен сервер push-уведомлений.
