# SLOT — демонстрационный сайт PDR-студии

Мобильный прототип двух ролей: клиент записывается на осмотр и услуги, владелец управляет расписанием, услугами, информацией о студии и фотографиями. На первом плане — бренд бизнеса «AL QUOZ PDR STUDIO», SLOT показан небольшой подписью. Интерфейс доступен на русском и английском. Для запуска достаточно открыть `index.html` в браузере или разместить папку на статическом хостинге.

## Демо-профили

Сайт открывается как клиентская страница студии. Панель владельца доступна через маленькую иконку в правом верхнем углу. Это демонстрационные роли без пароля: они предназначены для показа продукта, а не для реального разграничения доступа.

Записи, настройки и загруженные фото сохраняются в localStorage **этого браузера**. На разных устройствах они не синхронизируются. Для настоящих аккаунтов, общей записи и безопасного кабинета потребуется сервер, авторизация и хранилище изображений. Не используйте демо для реальных клиентских персональных данных.

## Возможности

- Пошаговая запись: студия и адрес → услуги и цены → свободное время → контакты; телефон начинается с `+971`.
- Анимированная шкала прогресса и проверка занятости.
- Просмотр, перенос и отмена собственных записей.
- Кабинет владельца: записи, подтверждение, завершение и отмена; создание записи вручную.
- Редактирование услуг, описания, адреса, телефона и часов работы.
- Загрузка и удаление фотографий работ и студии. Фото уменьшаются и хранятся локально в браузере.
- RU / EN, поддержка узких экранов и режима reduced motion.

## Проверка

`node --check app.js`

Для просмотра через локальный сервер: `python3 -m http.server 8000` внутри папки, затем открыть `http://localhost:8000`.
